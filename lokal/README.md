# Template Undangan Pernikahan Premium

Folder ini berisi editor template undangan pernikahan online. Format dasarnya mengikuti contoh undangan yang dilampirkan pengguna, tetapi sekarang pilihan desainnya bisa diganti langsung dari halaman web.

## Link aplikasi

Jika GitHub Pages sudah aktif, buka:

```text
https://slee17an-spec.github.io/undangan-premium/lokal/
```

## Ukuran kertas

Default sudah diubah ke:

- **F4 / Folio: 21,59 × 33,33 cm**

Pilihan lain:

- A4: 21 × 29,7 cm
- Letter: 21,59 × 27,94 cm
- Legal: 21,59 × 35,56 cm

Saat mencetak, pilih ukuran kertas yang sama di dialog print browser agar hasilnya pas.

## Pilihan template yang bisa diakses online

Semua pilihan berikut tersedia langsung di halaman aplikasi:

- Ukuran kertas
- Warna aksen
- Background
- Ornamen / vektor
- Font judul / nama mempelai
- Font isi undangan
- Font Arab
- Label section
- Tampilkan / sembunyikan monogram
- Tampilkan / sembunyikan ornamen atas
- Tampilkan / sembunyikan ornamen bawah
- Tampilkan / sembunyikan bingkai

## Struktur undangan

### Sisi kiri

- Monogram inisial mempelai
- Bismillah
- Salam pembuka
- Kalimat pembuka
- Nama mempelai pria
- Nama mempelai wanita
- Waktu penyelenggaraan
- Hari/tanggal, jam, tempat, hiburan
- Ucapan kehormatan dan terima kasih

### Sisi kanan

- Salam penutup
- Kutipan Ar-Ruum ayat 21
- Judul pengundang
- Daftar keluarga pengundang

## Cetak

Template dicetak dalam 1 lembar berisi 4 panel:

- kiri atas: sisi isi undangan
- kanan atas: sisi keluarga pengundang
- kiri bawah: sisi isi undangan
- kanan bawah: sisi keluarga pengundang

## Fitur

- Edit semua teks utama
- Edit nama dan keterangan mempelai
- Edit waktu, tempat, dan hiburan
- Edit ayat/kutipan
- Edit daftar keluarga pengundang
- Simpan draft otomatis di browser
- Export/import JSON
- Salin teks untuk WhatsApp
- Cetak atau simpan PDF dari browser

## Catatan

Aplikasi ini statis. Tidak memakai server, database, atau login. Data tersimpan di browser melalui `localStorage`.
